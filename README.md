# Grid Door Mod

A Minecraft mod that adds a grid door with fence connectivity and worker card access.

## Features

- Adds a grid door block that connects with fences
- Requires a worker card to open the door

## Requirements

- Minecraft Forge 1.19.2
- Minecraft 1.19.2

## Installation

1. Download the mod JAR file.
2. Place the JAR file in your Minecraft mods folder.
3. Launch Minecraft with Forge.

## Usage

1. Craft a grid door using the provided recipe.
2. Place the grid door in the world.
3. Use a worker card to open the door.

## Configuration

The mod does not have any configuration files.
